Python Code (CLI Mini Project) 
# ============================================
# SMART WASTE SEGREGATION TRACKER
# Mini Project
# Language: Python
# ============================================

# Waste database
waste_data = {
    "banana peel": ("Organic Waste", "Green Bin", "Compost it"),
    "apple": ("Organic Waste", "Green Bin", "Compost it"),
    "vegetable waste": ("Organic Waste", "Green Bin", "Compost it"),

    "plastic bottle": ("Plastic Waste", "Blue Bin", "Recycle it"),
    "milk packet": ("Plastic Waste", "Blue Bin", "Recycle it"),
    "plastic cover": ("Plastic Waste", "Blue Bin", "Recycle it"),

    "newspaper": ("Paper Waste", "Blue Bin", "Recycle it"),
    "paper": ("Paper Waste", "Blue Bin", "Recycle it"),
    "cardboard": ("Paper Waste", "Blue Bin", "Recycle it"),

    "glass bottle": ("Glass Waste", "Glass Bin", "Recycle it"),
    "glass": ("Glass Waste", "Glass Bin", "Recycle it"),

    "battery": ("Hazardous Waste", "Red Bin", "Dispose safely"),
    "medicine": ("Hazardous Waste", "Red Bin", "Dispose safely"),

    "mobile": ("E-Waste", "E-Waste Bin", "Send to E-Waste Center"),
    "laptop": ("E-Waste", "E-Waste Bin", "Send to E-Waste Center"),
    "charger": ("E-Waste", "E-Waste Bin", "Send to E-Waste Center"),
}

print("=" * 50)
print("      SMART WASTE SEGREGATION TRACKER")
print("=" * 50)

while True:

    item = input("\nEnter Waste Item: ").lower().strip()

    found = False

    # Simple NLP (Keyword Matching)
    for key in waste_data:
        if key in item or item in key:
            category, bin_name, instruction = waste_data[key]

            print("\nWaste Category :", category)
            print("Dustbin        :", bin_name)
            print("Instruction    :", instruction)

            found = True
            break

    if not found:
        print("\nWaste item not found.")
        print("Please dispose according to your local waste management rules.")

    choice = input("\nDo you want to check another item? (yes/no): ").lower()

    if choice != "yes":
        print("\nThank you for using Smart Waste Segregation Tracker.")
        break
Technical Explanation
Project Overview

This Python script is a standalone command-line application designed for smart waste classification. It operates using an in-memory dictionary data structure and bidirectional keyword matching without requiring external database dependencies.

1
Waste Database Dictionary (`waste_data`)

Stores waste items mapped to 3-element tuples containing classification details:

  • Waste Category: Organic, Plastic, Paper, Glass, Hazardous, or E-Waste.
  • Dustbin: Target bin color (Green, Blue, Red, Glass, E-Waste Bin).
  • Instruction: Actionable guidance (Compost, Recycle, Send to E-Waste Center).
2
Formatted Header Banner

Uses print("=" * 50) to create visual separator lines and print a clear title banner for console presentations.

3
Interactive Loop (`while True`) & Input Cleaning

Runs an infinite loop accepting user queries. The input string is normalized using .lower().strip() to make input matching case-insensitive and trim extra spaces.

4
Simple NLP Keyword Matching Loop

Iterates over database keys checking substring presence in both directions:

if key in item or item in key:

Matches user entries like "used plastic bottle" or "paper" accurately, unpacks tuple values, displays results, and breaks the loop.

5
Fallback Handling (`if not found`)

If an item is not in the database, notifies the user and suggests referring to local municipal waste disposal rules.

6
Continuation Check & Exit

Asks Do you want to check another item? (yes/no). If response is not "yes", prints a exit message and breaks out of the loop.
